# **App Name**: Career Catalyst AI

## Core Features:

- Secure Resume Upload & Text Extraction: Allows users to upload PDF or DOCX resumes securely. Utilizes AI/NLP tools to extract and categorize text for further analysis and optimization. Stores files in the TiDB Cloud database.
- Target Role Selection & AI Skill Gap Analysis: Users can select their desired career role. An AI tool compares current resume skills against target role requirements, identifying missing, important, and optional skills to highlight career gaps.
- AI Resume Optimizer: Automatically enhances resumes by rewriting weak bullet points, adding ATS-friendly keywords, improving formatting, and incorporating industry-standard terminology using an AI tool.
- ATS Scoring System & Analytics Dashboard: Calculates an ATS (Applicant Tracking System) score based on skill match, keywords, and formatting. Displays the score, strengths, weaknesses, and suggestions via an intuitive analytics dashboard.
- AI Learning Roadmap Generator: Generates a personalized learning roadmap based on identified skill gaps for the target role, detailing beginner, intermediate, and advanced steps to acquire necessary competencies using an AI tool.
- Optimized Resume Download: Enables users to download their AI-optimized resumes in PDF or DOCX format, leveraging professional, ATS-friendly templates.
- User Authentication & Profile Management: Provides secure user registration and login functionality using JWT. Stores user profiles and related resume data in the TiDB Cloud database.

## Style Guidelines:

- Scheme: Dark mode to convey sophistication and focus, aligning with 'Advanced AI' and 'SaaS' aesthetic.
- Primary color: Deep, sophisticated indigo-violet (#5533B5), symbolizing intelligence and professional aspiration, suitable for headings and interactive elements against a dark background. (HSL: 250, 60%, 45%).
- Background color: A very dark, almost off-black with a subtle indigo tint (#19151E), providing a luxurious and immersive experience. (HSL: 250, 15%, 10%).
- Accent color: A vibrant, clear sky blue (#A7CCF7), providing strong contrast for calls-to-action, alerts, and key information, signifying clarity and progress. (HSL: 220, 80%, 70%).
- Headline font: 'Space Grotesk' (sans-serif) for a modern, techy, and sharp appearance, resonating with the AI and data analysis themes.
- Body font: 'Inter' (sans-serif) for high readability, neutrality, and professional appeal, ensuring comfortable reading of analytical content and descriptions.
- Utilize modern, clean, line-based icons for all features and navigation elements to maintain a professional SaaS aesthetic. Icons should visually represent career concepts, data analysis, and AI functions.
- Employ a modular, card-based layout inspired by Tailwind UI, enabling a clean organization of complex information like dashboards, skill gaps, and roadmaps. Incorporate subtle glassmorphism effects for depth.
- Implement subtle, purposeful animations using Framer Motion for transitions, state changes, and user feedback, enhancing interactivity without distracting from the professional content.
